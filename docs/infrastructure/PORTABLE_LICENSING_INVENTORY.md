# Portable handout — licensing inventory of every redistributable component

**Status:** ACTIVE

> **INVENTORY ONLY — NO LEGAL CLEARANCE GIVEN.** This document is the factual
> input to `PORTABLE_STACK_MANIFEST.md` §(d) row 3 ("licensing check"). It
> records, for each thing a handout bundle would copy onto someone else's
> machine, what the artifact itself says about its license, where that was read,
> and what is still unknown. It does not conclude that anything may be
> redistributed; that is the operator's / counsel's sign-off, and row 3 stays
> OPEN until a human records it.

**Created 2026-09-29.** Every "as stated in the artifact" cell below was read
off a file on this container on 2026-09-29 (`models/*/README.md`, `config.json`,
`.venv/lib/python3.11/site-packages/*.dist-info/METADATA` and its `licenses/`
files, `spike/*/LICENSE*`, `Cargo.toml`). Cells marked **(web, 2026-09-29)** were
fetched from the named upstream page because nothing on disk states the
license. **NOT STATED** means the directory that would be shipped carries no
license text or license field of its own; the "inherited candidate" is the base
checkpoint's license, which is the *starting* assumption a decision-maker would
verify, not a finding.

Bundle scope: the serve path as `THIN_CLIENT_SWAP.md` §"What runs here now"
describes it and as the two existing bundle recipes copy it —
`scripts/portable_linux/` (`PORTABLE_LINUX_BUNDLE.md`, env-var contract
`SFU_SPLADE_MODEL_PATH` / `SFU_EMBEDDING_MODEL_PATH` / `SFU_CE_MODEL_PATH`) and
`scripts/portable_socsci/` (`PORTABLE_SOCSCI_WINDOWS_BUNDLE.md`, dense stripped,
`splade_onnx_fused` only). Anything under `models/` that neither the served
defaults nor the recipes load is listed once in §5 as not shipped.

## 6. Headline summary (2026-09-29)

- **Clear, artifact-stated, redistribution-permitting licences:** the seismic
  fork (MIT), vectorium fork (MIT), toolkit fork (Apache-2.0), and every
  top-level Python wheel read off its dist-info (BSD-3 / MIT / Apache-2.0 /
  numpy's compound permissive expression). The embedder v5 / v4-bge directories carry
  the BAAI MIT card. OpenAlex data is CC0 per the AWS Open Data registry entry
  and the repository's own research record.
- **NOT STATED in the shipped artifact (licence known only from the base
  model's web card):** `splade_onnx_fused` / `splade_onnx*` (Apache-2.0
  candidate), the borrowed bert-base-uncased tokenizer (Apache-2.0 candidate),
  `sfu-cross-encoder-v1`, `-baseline`, `-v1-onnx-int8` (Apache-2.0 candidate),
  and the SFU fine-tunes' own terms (never chosen).
- **Unlicensed:** this repository's code and the fork patches — no LICENSE file
  anywhere in the repository or its upstream.
- **Not determinable from disk:** 209 of 247 Rust crates statically linked into
  the engine; ~45 transitive Python wheels; the third-party notices inside the
  install-only CPython tarball.
- **Open legal question that no file answers:** redistributing reconstructed
  plaintext abstracts (`packed/`, the socsci sidecars) when OpenAlex itself
  ships them only as `abstract_inverted_index` "for legal reasons".

## 7. What the operator must decide

1. **A licence for the project's own code** (and therefore the fork patches and
   the launcher scripts) — nothing can be handed out until one exists.
2. **Whether reconstructed plaintext abstracts may ship** (§2 open question a),
   or whether the bundle must ship the inverted-index form / title-only for
