## O2 residual — BM25F between the buffer delete and `reload()`

- **Status string:** FIXED 2026-10-01 (2fc2cb5c) for one freeze per
  `reload()`. Residual OPEN: when two freezes happen without a `reload()` in
  between, the BM25F leg misses the older freeze until `reload()`. Second
  defect found and fixed in the same commit: ingest auto-freezes never deleted
  from the buffer tantivy, so frozen docs stayed there forever and BM25F
  returned them twice after `reload()`.
- **Tests (failing first).** `scripts/tests/test_delta_bm25f_freeze_window.py`
  (5 tests; 4 failed before the fix, on synthetic roots):
  1. Frozen docs are visible to BM25F after `flush`, before `reload()`. Before
     the fix the leg returned `set()`.
  2. No duplicate BM25F hits after `reload()` of an ingest auto-freeze. Before
     the fix, `2 == 1`.
  3. After freeze N, the buffer tantivy holds exactly gen 0 plus gen N.
  4. Ingest auto-freezes garbage-collect older generations.
  5. Deleted or loaded docs are never served from the buffer (passed before
     the fix, kept as a guard).
- **Fix.**
  - Serving (`delta_layer.py`): `keep_hit` drops a hit from the buffer
    tantivy section whose id is not in the buffer view (`_buffer_rows`). That
    view has been O2-exact since c6a9d4de and is not re-parsed on a freeze.
    `filter_hits` calls `refresh_buffer()` only when a buffer hit is present.
    When the ledger is unchanged, that call costs two `stat`s.
  - Ingest (`cli.py`, `buffer.py`): after every freeze (`flush` and both
    `ingest` auto-freezes), `BufferWriter.retain_only(keep)` keeps gen 0,
    `building`, and the just-frozen generation, and deletes everything else.
    The buffer tantivy is therefore bounded by the buffer plus one generation.
- **Cost.**
  - Gate off: none. `filter_hits` is only reached with a delta layer.
  - Gate on: one `any()` over the hit list, plus two `stat`s when a buffer
    hit is present.
  - Per freeze: one enumeration of the buffer tantivy ids (bounded by the
    buffer plus one generation) and one commit.
  - Re-parse on freeze: none.
- **Why the residual stays.** Only serving knows what is loaded, and serving
  never writes to the delta root. To close it, ingest would have to learn
  that `reload()` happened (e.g. an acknowledgement file written by serving),
  or serving would have to attach unloaded generation sections lazily. Design
  only.
- **Invariant.** `docs/CODE_INVARIANTS.md`, "Buffer read side" paragraph
  (BM25F side).

## O19 follow-up — why lower-casing changed BM25F hits

- **Status string:** CAUSE FOUND + FIXED 2026-10-01 (d4e6a29f): keep
  lower-casing (it is the consistent behaviour). Fixed two remaining parse
  failures, and an unparseable query now returns no lexical hits instead of
  raising. Served-index hit counts: see the "Served index" block below.
- **Cause (measured).** Tantivy's QueryParser collapses a repeated query word
  only by its surface form, before the field tokenizer lower-cases it.
  - Before 99e2b663: "How ... how" became two identical `TermQuery("how")`
    clauses, so that term counted twice. A same-case repeat ("how ... how")
    was always one clause.
  - Probe on a 4-doc index: "how how teams" gives 2 clauses (top score
    1.3366); "How how teams" gives 3 clauses (top score 2.0049); "Teams teams"
    gives 2 clauses and doubles the score of "teams teams".
  - Upper-case `AND`/`OR`/`NOT` were boolean operators, and `IN` raised.
  - Topic 117 ("How does psychological safety ... and how teams perform?") is
    exactly this case-variant repeat of "how".
  - Ruled out: a non-default tokenizer. The served `social_sciences__recent`
    tantivy `meta.json` uses tokenizer `default` for `title` and `abstract`
    (`raw` for `id`/`doctype`), the same as `SectionBuilder`.
- **Which behaviour is correct.** Lower-cased. Each distinct word is one
  clause whatever its capitalisation, which matches the case-insensitive
  tokenizer. The old weighting depended on whether a word happened to appear
  in two case variants, usually a sentence-initial function word ("How",
  "What", "The"). Ranking quality without qrels is UNMEASURED. See the
  known-item ranks in the "Served index" block.
- **Parse-level counts.** Measured with
  `scripts/experiments/eval_delta_ingest_o19_case_parse.py parse`, lock-free,
  on an empty tmp index with the served schema.
  - Results: `data/eval_results/delta_ingest_O19_case_parse_20261001.json`
    (rows: `/home/vscode/work/delta_ingest/fix/o19_parse_rows.json`),
    2026-10-01 15:39Z.
  - Queries: the 120 topics of `data/sfu_eval_queries.json`, and the title
    sample of `/home/vscode/work/delta_ingest/corpus_a/title_sample.json`
    (50,000; the M3 sample is its first 350).

  | set | parse differs pre vs post | reason: case-variant repeat / upper operator word | raise pre-99e2b663 | raise with 99e2b663 | raise now |
  |---|---|---|---|---|---|
  | 120 topics | 1 (index 117) | 1 / 0 | 0 | 0 | 0 |
  | 350 M3 titles | 27 | 23 / 4 | 10 | 2 | 0 |
  | 50,000 titles | 4,581 | 4,005 / 589 | 1,815 | 439 | 5 → no hits, no exception |

  The "raise pre" column counts titles that raised before 99e2b663. The 10
  of 350 matches M3.
- **Two parse failures that 99e2b663 still had** (439 of 50,000 titles, 2 of
  350):
  - Unicode whitespace (NBSP, U+2005, U+2009, U+3000) passes `str.isspace()`,
    so the sanitiser kept it, but tantivy's grammar does not treat it as a
    separator: 384 titles.
  - `'İ'.lower()` returns `i` + U+0307 (a combining dot), which the grammar
    rejects: 55 titles, all Turkish.
- **Fix** (`retriever.py`):
  - `bm25f_query_text` maps every non-alphanumeric character to an ASCII
    space. It lower-cases each alphanumeric unless that yields several code
    points; those are kept, and the field tokenizer lower-cases them exactly
    as at index time.
  - On all 49,681 queries where 99e2b663 parsed, the new parse is identical
    to its parse. So the hit change versus 99e2b663 is limited to the 439
    queries that raised before.
  - `_bm25f_leg` skips a section whose `parse_query` raises `ValueError` (the
    leg returns no hits).
- **Remaining 5 of 50,000** raise "Only excluding terms given": each is a long
  CJK run over tantivy's 40-byte token limit, so every token is dropped.
  `search_rrf` now degrades instead of raising.
- **Tests (failing first).** `scripts/tests/test_bm25f_query_text_unicode.py`
  (7 tests; 5 failed before the fix): NBSP, U+2005 and U+3000 parse; `İ`
  parses and matches the indexed `BİR`; "How ... how" is one clause; ASCII
  output equals plain `.lower()`; an all-too-long CJK query gives `[]` from
  `_bm25f_leg`. `test_bm25f_query_text.py` is unchanged and green.
- **Invariant.** The `docs/CODE_INVARIANTS.md` O19 entry is rewritten. The
  old "changes no token and no hit" claim is withdrawn.

### (b) Served dotvbyte code equality — MEASURED, 20,000 / 20,000 equal

Measured 2026-10-01 ~16:09Z, commit c0a02924. Lock-free light run (≤ 4
threads, peak RSS 1.24 GB); timings invalid.

- **Sample.** 20,000 random rows of the shard-0 twin (seed 20261001), read
  with `BaseVectorStore.vectors`. All 20,000 were reused exactly, 0 refused.
- **Delta chain.** The reused vectors were written as `seismic_line` JSONL
  and built with `generation.build_seismic_shard`: stock → c1a f16 →
  dotvbyte v2 per-doc, 20,000 docs, nnz 1,766,105.
- **Comparison.** Each doc's dotvbyte v2 record was decoded from the delta
  shard and from the served `global_shard0of8.dotvbyte.e5.v2.mmap` (staged
  local copy) to {token: u8} plus the f16 vmax header. Component ids are
  mapped back through each shard's `forward_encoder.bin` inverse mapping and
  `token_to_id_map.bin`.
  - The staged records are **byte-equal to the `data/` copy for all 20,000**.
  - The decoder + quantiser was validated first: 5,000/5,000 equal against
    the c1a f16 forward of a local delta generation.
- **Result: 20,000 / 20,000 docs equal.** nnz, vmax bits and every
  (token, u8) pair match; 0 differ. The Python port of the converter's
  quantiser also matches the served codes 20,000/20,000.
- **Conclusion.** For a reused vector, the served u8 codes of the delta copy
  equal those of the base copy. This was inferred before; it is now measured.
