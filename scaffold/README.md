# scaffold/ — founding seed for the portable-client split repo

**Status:** ACTIVE

`portable_client_seed/` is the bootstrap for `sfu-library-portable`, the
Rust/Tauri handout client that consumes the artifacts this repository builds. It
contains that repository's `CLAUDE.md`, `CONTRACT.md` (the artifact contract
between the two repositories), `BOOTSTRAP_PLAN.md`, and `import_fixtures.sh`. This
repository never builds the client; see `docs/infrastructure/PORTABLE_STACK_MANIFEST.md`.
