# scaffold/ — founding seed for the portable-client split repo

**Status:** ACTIVE

`portable_client_seed/` is the bootstrap for `sfu-library-portable`, the
Rust/Tauri handout client that consumes the artifacts this repo builds. It
contains that repo's `CLAUDE.md`, `CONTRACT.md` (the artifact contract
between the two repos), `BOOTSTRAP_PLAN.md`, and `import_fixtures.sh`. This
repo never builds the client; see `docs/infrastructure/PORTABLE_STACK_MANIFEST.md`.
